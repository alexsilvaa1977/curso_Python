# Módulo 08 — Web e APIs

Este módulo é a ponte entre "saber Python" e "ser um desenvolvedor
backend": como a web funciona, e como construir uma API que outros
sistemas (ou um frontend) podem consumir.

**Objetivos do módulo:**
- Entender os fundamentos de HTTP e o estilo arquitetural REST.
- Construir uma API simples com Flask.
- Construir uma API com FastAPI, incluindo validação automática com
  Pydantic.
- Persistir dados com SQLite via um ORM (SQLAlchemy).
