# Exercícios — Aula 3: Estruturas de controle

1. Peça um número e diga se ele é positivo, negativo ou zero, usando
   `if`/`elif`/`else`.

2. Use `for` com `range()` para exibir todos os números pares entre 1 e 30.

3. Use `while` para pedir números ao usuário repetidamente até que ele
   digite `0`. No final, exiba a soma de todos os números digitados
   (não conte o `0`).

4. Escreva um `for` que percorra os números de 1 a 50 e, usando
   `continue`, exiba apenas os múltiplos de 3.

5. Escreva um `for` que percorra os números de 1 a 1000 e pare (`break`)
   no primeiro número maior que 200 que seja divisível por 7 ao mesmo
   tempo, exibindo esse número.

6. **Desafio (Fizz Buzz):** para os números de 1 a 30, exiba `"Fizz"` se
   o número for múltiplo de 3, `"Buzz"` se for múltiplo de 5, `"FizzBuzz"`
   se for múltiplo dos dois, e o próprio número nos outros casos.
