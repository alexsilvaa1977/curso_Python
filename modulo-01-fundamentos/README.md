# Módulo 01 — Fundamentos

Revisão rápida e sólida da base da linguagem, para garantir que não fiquem
lacunas antes de avançar para tópicos de desenvolvedor.

**Objetivos do módulo:**
- Ter o ambiente Python configurado e saber rodar scripts e notebooks.
- Entender tipos, variáveis e operadores.
- Controlar o fluxo de um programa com `if`, `for` e `while`.
- Manipular texto com confiança (strings e formatação).
- Escrever código legível (PEP 8) e já usar git desde a primeira linha.
