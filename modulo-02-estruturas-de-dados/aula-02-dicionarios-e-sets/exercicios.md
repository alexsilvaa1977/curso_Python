# Exercícios — Aula 2: Dicionários e sets

1. Crie um dicionário representando um produto (`nome`, `preco`,
   `estoque`). Atualize o `preco` e adicione uma nova chave `categoria`.

2. Peça 3 pares de "nome" e "idade" ao usuário e monte um dicionário
   `{nome: idade}`. No final, exiba todas as pessoas com idade maior que
   18 usando `.items()`.

3. Dado o dicionário `estoque = {"maçã": 10, "banana": 0, "uva": 5}`,
   exiba apenas os produtos com estoque maior que zero.

4. Crie dois sets de nomes de alunos (`turma_a` e `turma_b`) e exiba:
   alunos que estão nas duas turmas, alunos que estão só na turma A, e
   todos os alunos únicos das duas turmas juntas.

5. Dada uma lista de e-mails com duplicados, use `set()` para obter a
   lista de e-mails únicos e depois converta de volta para lista
   ordenada.

6. **Desafio:** conte quantas vezes cada palavra aparece em uma frase
   (dica: divida a frase com `.split()`, percorra as palavras e use um
   dicionário para acumular a contagem, com `.get(palavra, 0) + 1`).
