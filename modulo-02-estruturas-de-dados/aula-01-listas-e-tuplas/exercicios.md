# Exercícios — Aula 1: Listas e tuplas

1. Crie uma lista com 5 nomes. Adicione um sexto nome com `.append()` e
   remova o segundo nome usando `.pop(1)`.

2. Dada a lista `numeros = [4, 8, 15, 16, 23, 42]`, calcule a soma de
   todos os elementos sem usar `sum()` (use um `for`).

3. Peça 5 números ao usuário, guarde-os em uma lista, e exiba a lista
   ordenada de forma crescente e depois decrescente, sem alterar a lista
   original (dica: `sorted(lista, reverse=True)`).

4. Crie uma tupla representando as coordenadas `(x, y)` de um ponto e
   escreva uma função... ainda não vimos funções formalmente (isso é
   módulo 3), então apenas escreva o código que calcula a distância do
   ponto até a origem `(0, 0)` usando a fórmula
   `((x**2 + y**2) ** 0.5)`.

5. Dada `matriz = [[1, 2], [3, 4], [5, 6]]`, use dois `for` (um dentro do
   outro) para exibir cada elemento individualmente.

6. **Desafio:** dada uma lista de números com possíveis repetições, crie
   uma nova lista contendo apenas os valores **sem repetição**, mantendo
   a ordem da primeira aparição de cada número (não use `set()` ainda —
   isso é conteúdo da próxima aula; resolva com uma lista auxiliar e
   `if valor not in nova_lista`).
