# Exercícios — Aula 3: Comprehensions

1. Crie uma list comprehension que gere os cubos (`n ** 3`) dos números
   de 1 a 10.

2. Dada uma lista de palavras, crie uma nova lista contendo apenas as
   palavras com mais de 4 letras, usando list comprehension.

3. Dada uma lista de temperaturas em Celsius, crie uma nova lista com as
   temperaturas convertidas para Fahrenheit (`f = c * 9/5 + 32`), usando
   comprehension.

4. Dado um dicionário `{produto: preco}`, crie um novo dicionário apenas
   com os produtos cujo preço é maior que 10, usando dict comprehension
   com condição.

5. Dada uma frase, crie um set com todas as vogais que aparecem nela
   (dica: percorra os caracteres da frase e filtre com
   `if letra in "aeiou"`).

6. **Desafio:** dada uma lista de listas de números (uma "matriz"),
   crie, em uma única comprehension aninhada, a lista de todos os
   números **pares** presentes em qualquer posição da matriz.
