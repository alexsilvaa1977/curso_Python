# Módulo 02 — Estruturas de dados

Aqui você aprende a organizar e manipular coleções de dados — a base de
praticamente todo programa real.

**Objetivos do módulo:**
- Escolher entre listas, tuplas, dicionários e sets conforme o problema.
- Usar comprehensions para criar coleções de forma concisa.
- Entender noções básicas de desempenho ao manipular grandes coleções.
