# Exercícios — Aula 1: Funções, parâmetros e retorno

1. Escreva uma função `eh_par(numero)` que retorna `True` ou `False`.

2. Escreva uma função `saudacao(nome, idioma="pt")` que retorne a saudação
   em português por padrão, mas em inglês se `idioma="en"` for passado.

3. Escreva uma função `calcular_area_retangulo(largura, altura)` que
   retorna a área. Chame a função com argumentos posicionais e depois com
   argumentos nomeados.

4. Escreva uma função `dividir(a, b)` que retorna o quociente e o resto
   da divisão (dois valores, usando `return a // b, a % b`).

5. Escreva uma função `maior_valor(lista)` que retorna o maior valor de
   uma lista, sem usar `max()`. Adicione uma docstring explicando o que
   ela faz.

6. **Desafio:** escreva uma função `validar_senha(senha)` que retorna
   `True` somente se a senha tiver pelo menos 8 caracteres e conter pelo
   menos um número (dica: percorra os caracteres e use `.isdigit()`).
