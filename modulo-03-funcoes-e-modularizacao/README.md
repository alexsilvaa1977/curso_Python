# Módulo 03 — Funções e modularização

Aqui você aprende a organizar código em blocos reutilizáveis (funções) e
a estruturar um projeto em múltiplos arquivos (módulos e pacotes) — a
base para escrever programas maiores do que um único script.

**Objetivos do módulo:**
- Criar funções com parâmetros, valores padrão e retorno.
- Entender escopo de variáveis, `*args`/`**kwargs` e funções `lambda`.
- Organizar código em módulos e pacotes, usando `import` corretamente.
- Gerenciar dependências de um projeto com ambientes virtuais.
