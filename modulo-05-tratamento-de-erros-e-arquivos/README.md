# Módulo 05 — Tratamento de erros e arquivos

🚧 **Em construção** — este módulo ainda não tem o conteúdo completo das
aulas. Este README descreve os objetivos e o índice planejado; o
conteúdo real será adicionado em uma fase seguinte do curso.

Programas reais lidam com entradas inesperadas e precisam ler/gravar
dados em arquivos — este módulo cobre como fazer isso de forma robusta.

**Objetivos do módulo:**
- Tratar erros previsíveis com `try`/`except`/`finally` sem "engolir"
  bugs silenciosamente.
- Criar exceções customizadas para erros específicos do seu domínio.
- Ler e escrever arquivos de texto e CSV.
- Serializar e carregar dados com JSON (e entender quando usar `pickle`).

## Aulas planejadas

1. Exceções: `try`/`except`/`finally`
2. Exceções customizadas
3. Manipulação de arquivos texto e CSV
4. Serialização: JSON e pickle
