# Módulo 06 — Testes e qualidade

Testes automatizados são o que separa "código que parece funcionar" de
"código em que se pode confiar" — essencial para trabalhar em equipe e
evoluir um projeto com segurança.

**Objetivos do módulo:**
- Escrever testes com `pytest`.
- Usar fixtures e mocks para isolar o código testado.
- Entender cobertura de testes e uma introdução a integração contínua.
- Usar `typing` e `mypy` para checagem estática de tipos.
