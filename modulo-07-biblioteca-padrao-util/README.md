# Módulo 07 — Biblioteca padrão útil

Python vem com uma biblioteca padrão enorme — conhecer os módulos certos
evita reinventar a roda e resolve boa parte dos problemas do dia a dia de
um desenvolvedor.

**Objetivos do módulo:**
- Manipular datas e horários com `datetime`.
- Usar `collections`, `itertools` e `functools` para simplificar código.
- Trabalhar com caminhos e arquivos de forma portátil com `pathlib`.
- Registrar eventos e depurar com `logging`.
